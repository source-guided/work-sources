# Maintain current work context

Follow the user's current task and existing owner records. Find relevant requirements, decisions, implementation and verification through the connected references; recheck changed sources on resume. Preserve provenance and distinguish accepted decisions from proposals and observations.

Use an existing project record, or a compact local record when needed. Track meaningful decisions, verified state, remaining questions and the next action. Do not duplicate authoritative documents or impose a fixed sequence, model or deadline. A source lookup can be the entire task.

For domain work, return to the reference entrypoint and use the project's selected role source. Do not assume a particular design, product or engineering source is installed. Apply user-supplied constraints and continue independently authorized work while resolving material gaps.
